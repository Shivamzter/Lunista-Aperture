# Lunista shader

## Features
1. LabPBR normal mapping.
2. LabPBR texture AO.
3. LabPBR F0/HCM support.
4. LabPBR emissives.
5. Tonemapping.
6. Cascaded shadow mapping.
7. Bloom.

## Planned
- Clouds
- Volumetric Lighting (should improve the overall feel of the shader).
- Fog.
- SSR (Screen Space Reflections).
- Water waves.
- Tonemap improvements.
